Briefing block

The paste-once instruction for any AI builder

Copy the block below into the start of any new conversation where you're asking an AI to build a Th1nk page or deck. It tells the builder what to read and what rules apply.

Paste-ready

Th1nk design briefing — for AI builders

You are building inside the Th1nk visual system. Before writing any HTML or CSS:

1. Read `Th1nk Design Spec.html` end-to-end. The :root block is the authoritative token set.
2. Use ONLY the named tokens. Do not introduce new colours, font sizes, or spacing values without flagging the gap to me first.
3. For HTML pages (web layer): use the fluid type scale (--fs-xs..--fs-3xl) and clamp-based spacing. Container max-width is --max-w (1120px) for programme pages, --max-w-wide (1340px) for wide content.
4. For decks at 1920x1080 (slide layer): use the absolute slide type scale (--t-mega 168px ONLY on cover + section divider, --t-display 96px, --t-title 72px, --t-large 56px, --t-subtitle 44px, --t-body 34px, --t-small 28px, --t-eyebrow 24px). Slide padding is --slide-px 120px, --slide-pt 100px, --slide-pb 80px.
5. Every slide must pick one named template from section "Slide templates" (cover, divider, statement, big-stat, three-cards, two-column, two-by-two, timeline, layered-list, quote, full-bleed-image, question-prompt). Do not invent bespoke layouts. If none fit, ask before extending.
6. Slide titles use Montserrat 800; body uses Inter 400. Eyebrows are uppercase Montserrat 700, --amber, 0.12-0.14em tracking.
7. Wordmark goes top-left, 36px high, 48px from top, inside slide padding (--slide-px).
8. Image aspect ratios are RECOMMENDED, not enforced. Prefer 16:9 (full-bleed), 4:3 (card), 1:1 (square), 4:5 (portrait). If you use another ratio, contain it inside a fixed box; never let it dictate the slide layout.
9. Work slide by slide for anything visual. Confirm the template choice before placing content.
10. When unsure, say "this is not in the spec — should I extend it, or use the closest match?" Do not silently invent.
Note on enforcement. This spec recommends but does not lock image aspect ratios — by choice. If you find slide drift returning because images bring their own dimensions, the lever is to tighten rule 8 in the briefing block from "RECOMMENDED" to "MUST be one of 16:9, 4:3, 1:1, or 4:5; crop the image to fit." Change it in one place, here.

Usage rule. One primary accent per slide or section. Amber is the default. Teal is reserved for "process / tech / contrast" framing. Green, purple, rose, red-soft are for category coding (e.g. 4-up grids); avoid using them as primary CTA accents.
Typography

Two families. One mono.

Montserrat for display. Inter for body. Fira Code for the rare technical block. No other fonts.

RoleFamilyWeight rangeUsed for
DisplayMontserrat300 / 600 / 700 / 800 / 900All headings, eyebrows, big stats, slide titles. Track tight (-0.02em).
BodyInter300 / 400 / 500 / 600 / 700All body, captions, table cells, slide body text.
MonoFira Code400 / 500Technical references, token names, code samples.
Slide-specific. In PowerPoint, theme fonts must be set to Montserrat (Heading) and Inter (Body). Do not let the default fall back to Calibri / Aptos / Segoe UI. Your older decks (e.g. Th1nk Uber Deck.pptx) mix five families across one deck — this is the canonical fix.

Slide type scale

Absolute pixel scale for 1920x1080 decks

Lifted from the Hidden Wiring deck. Eight named sizes, both in px (for HTML decks) and pt (for PowerPoint). Use the token, not the raw number.

TokenHTML (px)PPT (pt)Use
--t-stat200px96ptSingle huge stat. Display weight 900. Amber by default.
--t-mega168px96ptCover and section divider only. Outside the regular scale; reserved for dramatic openers and chapter breaks.
--t-display96px60ptSub-cover and closer signature; second-tier headline.
--t-title72px44ptSlide title. Montserrat 800. Use on every content slide.
--t-large56px34ptFeatured statement, big quote text.
--t-subtitle44px28ptCard title, secondary heading.
--t-body34px17ptParagraph body. Inter 400. Readable from back of room.
--t-small28px14ptCaption, card body, footnote.
--t-eyebrow24px12ptEyebrow label, decade-age, micro-label. Uppercase Montserrat 700.
Conversion rule. 1pt ≈ 1.333px at 96dpi (the PowerPoint default). To go from px to pt: multiply by 0.75. PowerPoint's font size dialog rounds to the nearest 0.5, so accept ±0.5pt drift between the HTML deck and PPT versions of the same slide.
Why this matters. Your Intro Talk PPT had body at 14pt — small for projection. The Hidden Wiring HTML deck had body at 34px (~17pt) — readable from the back row. The slide-type scale here resolves that drift by making 34px / 17pt the canonical body. Use it.

Image aspect ratios

Four canonical ratios (recommended)

Recommended, not enforced. If you use another ratio, contain it in a fixed box; never let an image's native dimensions drive slide layout.

16 : 9
Full-bleed hero
Slide cover, full-screen image, video frame. Native 1920x1080.
4 : 3
Card header
Pillar-card image, track-card image, classic photo crop.
1 : 1
Square
Avatar, medallion, social-style content, icon tile.
4 : 5
Portrait
Person photo, magazine-style portrait, side-rail image.
Soft rule (this is the drift risk you accepted). The Intro Talk used ad-hoc image ratios (0.74, 1.27, 1.33, 1.78) — four shapes the deck never declared. The Uber Deck used twelve. If layouts start drifting again, the first lever is to harden this section from "recommended" to "must be one of the four, crop to fit."
Slide frame

The 1920x1080 canvas

Every slide sits inside this frame. The frame defines where text starts, where the wordmark sits, and how far content reaches from the edges.

Wordmark
Title zone — --t-title 72px
Content zone — body, cards, image, stats
Footer reserve — slide number, section label (optional)
Canvas: 1920 × 1080 px (HTML) / 13.333" × 7.5" (PowerPoint).
Padding: --slide-px 120px (~6.25% L+R)  ·  --slide-pt 100px (~9% top)  ·  --slide-pb 80px (~7.4% bottom).

Wordmark rules

RuleValueWhy
Logo height36px (HTML) / 0.4" (PPT)Big enough to read, small enough not to compete with the title.
Distance from top48px (HTML) / 0.5" (PPT)Sits above the title zone with breathing room.
PositionTop-left, inside --slide-pxConsistent place to find it; mirrors th1nk.co.za nav.
On dark slidesWhite / 90% opacityAvoids stark white-on-black contrast.
On coverTop-left, smaller (28px) or centred at slide bottom with --t-eyebrow underCover slide can dramatise the wordmark.
