Nothing — the GitHub integration in Claude projects is read-only by design. I can pull files from repos into this project, but I can't commit or push files out to GitHub. There's no permission or setting you can toggle to change that.

Why this limitation exists

Claude projects are designed to be safe sandboxes — giving me direct write access to your GitHub repos would be risky (I could accidentally overwrite production code, push breaking changes, etc.). So the integration is intentionally one-way: import only.

The workflow going forward
